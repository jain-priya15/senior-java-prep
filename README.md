Big O: Time complexity: O(1), O(Log n), O(n), O(nlogn),O(n2)
Time complexity of O(n) is called linear time complexity.

Arrays are store in continuous block storage. It stores address of the values. So, if it is string the same amount of memory it will take while saving type of integer, character values.
Retrieve an element in Array is O(n).
Retrieve an index element in Array is O(1).
Add an element : O(1)
Insert or Update at a specific index: O(1)
Delete all: O(1)
Delete specific: O(n)

HashTables is a abstract data type.
When hash-key values of integers are same, it is called hash collision.
